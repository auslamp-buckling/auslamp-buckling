# AusLAMP Buckling

Research project for 3D lithospheric modelling and buckling.

## Components

| Component | Scope | Maintainer |
| --- | --- | --- |
| [regional_model_development_V2](https://github.com/auslamp-buckling/regional_model_development_V2) | First stage: lithospheric mesh generation and scalar mapping. | [Juan F. Giraldo](https://github.com/jfgiraldoa) |

Simulation components will be added in separate repositories as the project develops.

## Contributions

The mesh workflow comes from [Juan's existing V2 repository](https://github.com/jfgiraldoa/regional_model_development_V2), preserving its filenames, code, commit history, license and contributor notices. Its relationship to the earlier V1 workflow is documented in that repository.

Each component records its contributors and reviewers. Changes to the maintained branches require review by the designated maintainer; contributions retain their author attribution through Git commits.

This is a research collaboration, not an official Curtin University account.
